# AGRO / AgroFarm
AI + Agriculture + AgroTourism
Первый цифровой прототип проекта AGRO.

## Направление
Контейнерная ферма 20ft под управлением AI.

## Идея
Создание сети локальных AI-управляемых мини-ферм закрытого цикла.

Ключевая концепция:
**15 минут от грядки до стола**

## Что входит в проект
- контейнерные фермы
- сити-фермерство
- микрозелень и зелень
- гидропоника
- AI-автоматизация
- IoT-датчики
- дашборды управления
- цифровая платформа AGRO

## Текущий статус
